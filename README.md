
# Minha Garagem

Projeto desenvolvido durante as aulas de Python e Flask.

## Tecnologias utilizadas

- Python
- Flask
- HTML
- CSS
- SQLite
- Flask-SQLAlchemy

## Funcionalidades

- Catalogo de 10 veiculos
- Fotos e opcionais dos carros
- Formulario de feedback
- Cadastro, edicao e exclusao de notas
- Gerenciador de tarefas com SQLite

## Como executar

Instale as dependencias:

python -m pip install -r requirements.txt

Inicie o servidor:

python -m flask --app carros run --debug

Acesse no navegador:

http://127.0.0.1:5000
